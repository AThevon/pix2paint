# Pix2Paint v2 — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Rebuild Pix2Paint as a production-ready Vite + TS app with design excellence, IndexedDB persistence, export, and a proper homepage.

**Architecture:** Single-page app with two views (home + editor) managed via simple state. All image processing offloaded to a Web Worker. Projects persisted in IndexedDB with debounced auto-save. No framework — vanilla TS with typed DOM manipulation.

**Tech Stack:** Vite, TypeScript, Web Worker, IndexedDB (raw API, no lib), Canvas 2D, Google Fonts (Archivo + Space Grotesk)

**Design System:**
- Primary: `#6366F1` (indigo)
- Accent: `#F43F5E` (rose)
- Background: `#FAFAFA`
- Surface: `#FFFFFF`
- Border: `#E5E7EB`
- Text: `#1E1B4B`
- Text muted: `#6B7280`
- Font headings: Archivo (600, 700)
- Font body/UI: Space Grotesk (400, 500, 600)

### Task 4: IndexedDB persistence layer

**Files:**
- Create: `src/lib/db.ts`

**Step 1: Implement IndexedDB wrapper**

- `openDB()` — open/upgrade "pix2paint" DB v1, object store "projects" keyed by id
- `saveProject(project: Project): Promise<void>` — put project
- `getProject(id: string): Promise<Project | undefined>` — get by id
- `listProjects(): Promise<Project[]>` — getAll, sorted by updatedAt desc
- `deleteProject(id: string): Promise<void>` — delete by id
- `generateId(): string` — crypto.randomUUID()

All functions use raw IndexedDB API wrapped in Promises. No external lib.

---

### Task 5: Image processing engine

**Files:**
- Create: `src/lib/engine.ts`

**Step 1: Implement pixelisation + worker bridge**

- `pixelise(img: HTMLImageElement, blockSize: number): ImageData` — downscale with imageSmoothingEnabled=false
- `createWorker(): Worker` — instantiate the worker
- `processImage(worker: Worker, imgData: ImageData, tolerance: number): Promise<WorkerOutput>` — send to worker, return promise, handle job cancellation
- `generateThumbnail(img: HTMLImageElement, maxSize: number): Promise<Blob>` — create small thumbnail for project list
- `exportCanvas(...)` — render to offscreen canvas at fixed cell size (40px), return Blob. Parameters: pixelMap, palette, regions, options (showNumbers, showGrouped, showColored)
